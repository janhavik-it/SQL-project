#Healthcare Analytics & Hoapital Management SQL System
Developed a Healthcare Analytics & Hospital Management System using MySQL to manage and analyze 1,000+ healthcare records.
Designed a relational database covering Patients, Doctors, Appointments, Treatments, and Billing.
Implemented Primary Keys and Foreign Keys to maintain data integrity and reduce redundancy.
Used SQL Joins, Multi-Table Joins, CTEs, Subqueries, and Aggregate Functions for data analysis.
Applied Window Functions and RANK() to perform advanced analysis and comparisons. Analyzed hospital revenue, treatment costs, billing status, appointments, and patient trends.
Used CASE WHEN, Date Functions, and String Functions for data transformation and categorization.
Created an EER Diagram in MySQL Workbench to visualize database structure and relationships.
Generated actionable insights to support staffing optimization, revenue improvement, readmission reduction, and data quality.
Strengthened practical skills in SQL-based data analysis, relational database management, and business problem-solving.
