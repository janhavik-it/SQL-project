##Healthcare Analytics & Hospital Management SQL System

###Project Overview

This project is a Healthcare Analytics & Hospital Management System developed using MySQL to organize, manage, and analyze healthcare data across patients, doctors, appointments, treatments, and billing.

###Key Features
Designed a structured relational database for healthcare management.
Managed 1,000+ records across multiple interconnected entities.
Implemented Primary Keys and Foreign Keys to maintain data integrity.
Used DDL, DML, and DQL commands for database creation and data management.
Applied INNER JOIN, LEFT JOIN, RIGHT JOIN, and Multi-Table JOINs to integrate data.
Used Aggregate Functions such as SUM(), AVG(), COUNT(), MIN(), and MAX().
Applied CTEs, Subqueries, CASE WHEN, and Window Functions for advanced analysis.
Used RANK() to compare and rank treatments and billing records.
Applied Date and String Functions for data transformation and analysis.
Created an EER Diagram using MySQL Workbench to represent database relationships.

###Analysis 
Analyzed hospital revenue and billing status.
Evaluated treatment costs and treatment-related trends.
Analyzed doctor appointments and patient records.
Categorized billing amounts and patient groups using conditional logic.
Generated insights for staffing optimization, revenue improvement, patient readmission reduction, and data quality.
